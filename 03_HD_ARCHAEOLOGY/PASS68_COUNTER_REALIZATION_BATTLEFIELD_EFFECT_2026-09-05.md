## Mission

Determine how far the historical evidence can trace a selected counter from production authorization through actual battlefield effect, without converting correlation into causation.

## Production is not capability

The following distinctions are mandatory:

```text
COUNTER SELECTED
≠
COUNTER AUTHORIZED
≠
COUNTER TRAIN COMMAND
≠
COUNTER QUEUED
≠
COUNTER CREATED
≠
COUNTER DEPLOYED
≠
COUNTER ENGAGED
≠
COUNTER EFFECTIVE
```

A production command is therefore an intermediate causal event, not proof of strategic success.

## Replay evidence boundary

The reference replay/interpreter corpus contains substantial action and pending-lifecycle data, but the current interpreter did not promote a sufficient number of lifecycle transitions to W1/W2/W3 certainty. The evidence policy therefore preserves uncertainty rather than inventing object lineage.

Evidence matching priority:

1. exact object ID;
2. exact producer/builder/actor ID plus operation;
3. exact type + temporal + spatial correlation;
4. aggregate correlation;
5. heuristic inference.

Levels 4–5 cannot close an object-birth or battlefield-effect claim.

## Strategic implication

A counter should be evaluated on a capability-latency chain rather than on nominal existence alone:

```text
DECISION LATENCY
+
AUTHORIZATION LATENCY
+
QUEUE LATENCY
+
TRAINING LATENCY
+
DEPLOYMENT LATENCY
=
CAPABILITY LATENCY
```

A theoretically correct counter can fail strategically if it arrives outside the relevant threat window.

## Hostile QC

### “Train command proves the counter appeared.”

**Rejected.** Queue admission and object birth remain distinct evidence requirements.

### “A new unit near the enemy proves it was the produced counter.”

**Rejected unless identity/lineage is independently established.**

### “Temporal correlation proves battlefield effect.”

**Rejected.** Correlation can support a hypothesis but does not establish combat causation.

### “Parser uncertainty means the game failed to create the unit.”

**Rejected.** Parser uncertainty is not gameplay failure.
