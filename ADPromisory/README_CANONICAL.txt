This is the canonical rebuilt ADPromisory overlay.

Newest Byzantine modules come from the V2 patched Kingdom build, with the user-supplied War College V2 taking precedence for the After-Action module.
Original Promisory support files are included where they were supplied in the uploaded source set. Files that were not part of the supplied/verified source set are intentionally not invented.

Active root loads only the explicitly listed Byzantine modules plus finaling/defaultConstants.
