## Research pipeline
ENGINE MODEL -> INTERPRETER MODEL -> STRATEGIC MODEL -> BYZANTINE MODEL -> BOT

## Current frontier
Layer 1 machine knowledge is operationally advanced but still contains native unknowns. Layer 2 strategy reconstruction is the active intellectual frontier. Replay research is being used to turn observed commands into state, lifecycle, capability, timing, and strategic events without collapsing evidence into assumptions.

## Current replay doctrine
A replay command is evidence of a command, not automatically evidence of successful execution, completion, strategic intent, or outcome. Temporal proximity is evidence of possible causality, never proof. Disappearance is a termination candidate, never automatically death.

## Latest production doctrine
Production must be modeled as:
intent -> queue command -> admission -> queued -> started -> completed -> object birth -> capability availability -> deployment -> reinforcement.

DE_QUEUE is not completion. A queued unit is not an operational unit. A completed unit is not necessarily a battlefield capability.

## Byzantine thesis
The eventual AI should make enemy commitments pay a conversion tax: resources, production capacity, timing, map displacement, response latency, transition delay, and lost optionality—not merely casualties.

## What the future AI must preserve
1. Evidence before interpretation.
2. Provenance for every derived conclusion.
3. Explicit uncertainty and falsifiers.
4. Separation of observed, reconstructed, and counterfactual state.
5. Anti-hindsight decision boundaries.
6. The designer's logic, not merely source implementation.
7. Failed experiments as classified historical evidence, not as forgotten mistakes.
8. The distinction between engine facts and strategic inference.
