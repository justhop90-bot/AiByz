# Project Materials

The AEGIS project is larger than its runtime source. This index defines the material classes that must be preserved as durable institutional memory.

## Material classes

- Canonical project source — authorized current implementation and architecture.
- Strategy fossils — historical AI source mined for strategic knowledge, especially HD/2013 and V3.
- Research substrate — Promisory/ADPromisory and experimental architecture.
- Machine evidence — executable metadata, hashes, native analysis, scheduler/loader evidence, diagnostics, and engine contracts.
- Empirical evidence — replays, parsed replay data, validator results, controlled experiments, and runtime observations.
- Derived knowledge — archaeology reports, control maps, ledgers, hypotheses, lessons, and cross-validation records.

## Public-repository rule

Historical/vendor-derived AoE2 source is not redistributed in this public repository merely for convenience. Exact artifacts remain locally preserved and cryptographically identified. The repository preserves the resulting knowledge, methodology, provenance, and derived analysis.

If raw historical source must become version-controlled, use an explicitly authorized private repository or controlled archive.

## Authority

Material presence does not confer authority. Every artifact is classified by provenance and project contract before it can influence implementation.

`material → provenance → evidence → interpretation → validation → authority`

## Returnability

A future engineer should be able to identify what was used, which exact artifact was used, how it was verified, what was learned, what was inferred, what remains uncertain, and where the original artifact is preserved.
