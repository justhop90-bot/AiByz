## Evidence discipline

**direct runtime/native evidence > reproduced experiment > independent corroboration > reasoned inference > hypothesis**

Preserve the following distinctions:

- string reference != call graph;
- declaration != implementation;
- replay observation != native state;
- command issuance != execution success;
- successful execution != strategic success;
- historical source != current executable;
- pointer into a function != semantic ownership;
- `.pdata` geometry != semantic naming;
- zero xrefs != absence;
- validator behavior != runtime behavior.
