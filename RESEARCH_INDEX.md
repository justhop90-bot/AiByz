**ACTIVE.** The verified HD/Promisory source is the reconstruction authority. The purpose is to understand both the code and the strategy game the programmer was trying to play proficiently.

## 5. Historical strategic architecture

The most useful recovered transition is:

`GAME PROBLEM → OBSERVATION → CLASSIFICATION/BELIEF → REQUIREMENT → CAPABILITY CANDIDATES → RESOURCE/TIMING EVALUATION → COMMITMENT → AUTHORITY → ACTION → POSTCONDITION → FAILURE/RECOVERY → REASSESSMENT`

Four implementation chains have priority:

- **C1 Threat → Capability:** `OBSERVE → CLASSIFY → REQUIRE → RESERVE → PRODUCE → VERIFY → REASSESS`
- **C2 Strategic transition:** `DESIRE AGE/TECH → PROTECT → FEASIBILITY → RESEARCH → VERIFY → REALLOCATE`
- **C3 Military lifecycle:** `CAPABILITY → COMMIT → ENGAGE → ASSESS → RETREAT/CONTINUE → REGROUP → RESTART/ABANDON`
- **C4 Information → action:** `INFORMATION GAP → SCOUT → SAFETY/UTILITY → MOVE → OBSERVE → UPDATE BELIEF`

C1 is the immediate next specification target.
