# AEGIS Planning Policy

The final-bot project has one active plan:

`docs/AEGIS_MASTER_PLAN.md`

All future design changes, capability additions, roadmap changes, qualification status changes, and implementation sequencing decisions belong there.

Other repository documents are one of:

- historical/source evidence;
- machine/ABI evidence;
- forensic records;
- procedures/standards;
- implementation candidates;
- experiments;
- durable institutional memory.

They are not alternate final-bot plans.

**Rule:** do not create another blueprint, master plan, addendum, reconciliation, or revised plan. Update the master plan instead. Preserve underlying evidence in the appropriate evidence layer when necessary.
