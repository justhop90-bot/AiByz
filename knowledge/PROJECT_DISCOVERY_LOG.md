# AEGIS Project Discovery Log

This file is the index for durable discoveries. It is intentionally an index rather than a narrative transcript.

## Machine discoveries

- AoE2DE AI operates through an `.ai/.per` rule-script substrate.
- Rule scheduling exposes rule identity, sorted execution order, priorities, intervals, enable/disable controls, and execution diagnostics.
- Goals, strategic numbers, timers, and facts form a practical state/sensor substrate.
- UP/native interfaces require evidence classification; semantic identifiers must not be conflated with class identifiers.
- XS is a qualified capability surface, not blanket authority.
- Validator behavior must be distinguished from actual target-build engine behavior.

## Strategy discoveries

- V3 contains useful strategic intent but is fragmented across local heuristics and multiple writers; it should be mined, not copied wholesale.
- The HD AI contains substantial embedded strategic knowledge through strategy selection, contextual economy policies, military commitment, timing, transitions, timers, fallback behavior, and stateful attack/retreat logic.
- The HD source is therefore a primary strategic archaeology specimen.
- Repeated local rules can be generalized into strategic principles, transition principles, economic principles, and meta-knowledge.

## Architectural discoveries

- Strategy should be represented as state transformation under uncertainty.
- Capability is a stronger abstraction than unit count alone.
- Production is a capability pipeline rather than an isolated train command.
- Opponent modeling should maintain beliefs and alternatives rather than one prediction.
- Initiative, information value, timing, resource taxation, and failure recovery belong in the strategic model.

## Methodological discoveries

- Evidence provenance must survive cleanup and refactoring.
- Failures are knowledge and should be preserved with their falsifying evidence.
- Canonical, experimental, evidence, and archive material require explicit boundaries.
- Major implementation must be traceable back to evidence and forward to executable machine interfaces.

## Continuation

New discoveries should be appended as atomic records or linked to the appropriate knowledge ledger. This index should remain concise enough to function as an entry point for a new engineer.
